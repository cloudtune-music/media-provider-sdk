# Media Provider SDK

Media Provider SDK defines the plugin contract used by Media Provider Server.

It provides:

- `MediaProvider`
- `ProviderCapabilities`
- `ProviderSearchResult`
- `ProviderStream`
- Provider exception types
- Plugin entry-point constants

The SDK is provider-neutral and does not implement any media source itself.

## Requirements

Python 3.12+
